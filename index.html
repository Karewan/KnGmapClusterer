KnGmapClusterer v5 — examples

API key in .env.local (VITE_GMAPS_KEY=...). Without a key, Google displays the maps in development mode.

  • Basic clustering — 5,000 points, default options
  • Markers — one or several markers without clustering, add, remove, move
  • SVG markers — SVG pins and badges, gallery, donut by category
  • Big volume, SVG — 200k real SVG markers without clustering
  • Big volumes — from 10k to 1M points, worker, FPS
  • Dynamic style — color from a closure, aggregates, donut, SVG/PNG icons
  • Pinned and duplicates — always visible points, stacked duplicates, filter
  • Heatmap — noise map in decibels, weighted heatmap, markers with info window
  • Zones — group perimeters (instead of clusters), open on click
  • Route — line with arrows, points by zoom, start/end/events, stats
  • Maps management — KnMaps, OSM/IGN tiles, theme, reuse, static map
  • Vue 3 — components and instance reuse
  • Benchmark — v4 vs v5 vs @googlemaps/markerclusterer
